# HEARTLAND economic engine - long-term stability and performance

Generated by `npm run stress`. All three worlds are the nine-country, eleven-zone test world (7 goods) with every government on the rule-based fiscal autopilot; no scripted shocks. "Largest stored number" is the largest absolute value in the whole saved state. Memory is `heapUsed` after a forced garbage collection, relative to the start. Each milestone also saves, restores and replays 26 weeks and compares with the uninterrupted run (bit-exact fingerprint).

Node v22.23.4, linux x64. Timing is for this machine only; see ECONOMY_DESIGN.md for phone estimates.

## Reading the results

- Conservation: the worst relative error of goods, money and bond ledgers over all audited weeks was 6.6e-15.
- Save/restore: every milestone replay was bit-identical.
- Memory: save size at 1,000,000 weeks is 256 KB versus 256 KB at 1,000,000 weeks; history is a fixed-size ring so state does not grow with the number of turns.
- Nominal magnitudes: with a 2% inflation target the price index reaches 2.37e-16 at 1,000,000 weeks; with a zero target it is 2.37e-16.
- Real magnitudes: the growing world's real GDP at the last milestone is 2.17e+4 (the stationary one: 2.17e+4).
