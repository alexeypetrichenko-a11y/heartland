**Small engine-side changes:**
- **Unpaid interest reported.** The budget report now shows interest a state failed to pay (`unpaidInterest`), which the engine adds to the debt. Without it, debt could not be fully reconciled in a payment crisis. This is reporting only; no rule changed.
- **Week 1 no longer depends on the player.** The first week is now resolved by the autopilot for every country, before any player decision, so it doesn't depend on which country the player picks. This is what lets one starting save serve every choice.
- **Saves record their world.** Session saves carry the fingerprint of the world they belong to. A starting save cannot be loaded into a different map.

**New tests** (`tests/handoff.test.ts`), by requested check:

| Requested check | What is tested |
|---|---|
| Deterministic starting-state generation | The committed file equals a fresh rebuild byte for byte. It has v2, week 1 and no player, and its world fingerprint matches. |
| Compatibility with the fictional scenario | It starts from the **real** `selectCountry(createInitialState(), 'belora')`. For every player country it is identical to a fresh build, and stays so for 20 weeks. It is refused for a different seed, owner, country name or profile, for a week-2 save, and for bad JSON. Adjacency order does not matter. |
| Economic commands | All seven fiscal controls are applied from the next week. Partial changes touch only what is given. Out-of-range rates and shares, negative values and other countries' orders are refused with the engine's message. |
| Combined turn and rollback | A capture becomes an occupation (the legal owner is kept). Each failure leaves both states untouched: invalid economic command (the game turn does not even run), failing game turn, failing economic effect, weeks out of step, a game turn that doesn't advance one week. The next valid week equals one where the refused attempts never happened. |
| Single authoritative treasury and debt | For 155 weeks, every week, every country: treasury change = revenue − expenditure + borrowing − repayment. Debt change = borrowing − repayment − default write-off + unpaid interest. Total money in circulation equals the money issued by the central banks. All of this holds through a deliberate crisis (no taxes, borrowing off, missed payments, then default). The legacy panel figure is the same treasury. |
| Save/load equivalence | At several weeks, starting from the starting save: same summary, same world fingerprint, same next week |
| Events and defeat | All 17 engine event types get a notice with the specified severity and no missing text. A real regime collapse of the player is flagged and comes first as `defeat`. |

The engine benchmarks (`reports/BENCHMARK.md`, `reports/BROWSER_BENCHMARK.md`) show no change beyond timing noise.

## 5. Remaining limitations

- **Integration not done.** The game is not connected yet; Codex applies `CODEX_HANDOFF.md`. Until then the game still runs T06.
- **Invented profiles.** The fictional region profiles are invented. The starting save fits only the fictional scenario. A change to the game's fixture needs a scenario update and regeneration by Claude (`CODEX_HANDOFF.md` §8).
- **Starting adjustment.** The first weeks show a price adjustment: inflation of about 7–11% in week 1, about 4–5% after a year. Growth is hidden for the first half year.
- **GDP and territory.** GDP and growth include occupied regions, so a capture shows as a jump.
- **AI countries** use only the fiscal autopilot.
- **Money units.** Illustrative units with decimals, and one shared currency.
- **Not measured** on an iPhone or in Safari.
- **Long-run collapse.** The documented collapse after about 290 years is far beyond game lengths.
